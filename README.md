# AetherRAG – Agentic Multi-Agent RAG Chatbot

An Agentic AI-powered RAG chatbot built using LangChain, CrewAI, ChromaDB, FastAPI, and AWS EC2.

## Features

* Multi-agent workflow using CrewAI
* Document ingestion and vector search
* Context-aware LLM responses
* Source-based response generation
* FastAPI backend
* Docker deployment
* AWS EC2 hosting

## Tech Stack

* Python
* LangChain
* CrewAI
* ChromaDB
* FastAPI
* Docker
* AWS EC2
* Streamlit / React

## Overview

The system processes uploaded documents, retrieves relevant context using vector search, and generates intelligent responses using LLMs with source references.
